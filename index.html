Google setup

Drive and Firestore

Both Google Drive and Cloud Firestore sign in with the same OAuth client. Firestore additionally needs its project ID.

The client ID is stored per device. Use the setup link to carry it to your phone in one tap, or paste it into DRIVE_CLIENT_ID near the top of this file so every device gets it automatically.

Needed only for the Cloud Firestore source. Your Firebase or Google Cloud project ID — a public identifier, not a secret. Access is governed by your Google sign-in and the project\'s IAM, so only accounts you have granted access can read it.

Simpler alternative on a desktop: keep daily-log-data.json in your Google Drive folder and connect it as a file. Drive syncs each save with no setup at all.
